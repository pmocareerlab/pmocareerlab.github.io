転職活動の山場は、内定ではありません。**本当の関門は、退職を切り出したあとに来ます。**

特にSIerのPMOは、案件の事情を理由に引き止められやすい立場です。「この案件が終わるまで」「後任が決まるまで」——そう言われて、結果的に内定を手放す人は珍しくありません。

この記事では、引き止めが起きる構造と、実際に辞められる人が何を準備しているのかを整理します。

---

## なぜPMOは引き止められやすいのか

引き止めの強さは、あなたの価値というより**代替のしにくさ**で決まります。PMOはここが特殊です。

{{< comparison-table title="PMOが引き止められやすい3つの理由" >}}
| 理由 | 中身 |
|------|------|
| 業務が属人化している | 課題管理の経緯・関係者の力関係が頭の中にしかない |
| 引き継ぎ資料が存在しない | 「調整」は手順書に落ちにくい |
| 代わりがすぐ立たない | 採用しても案件文脈の習得に数ヶ月かかる |
{{< /comparison-table >}}

つまり引き止めは、あなたが優秀だからというより、**会社が困るから**起きます。ここを混同すると、情に訴えられたときに判断がぶれます。

---

## 引き止めの典型3パターン

### パターン1：情に訴える

「君がいないと現場が回らない」「あれだけ任せてきたのに」。いちばん多く、いちばん効きます。

これが効くのは、PMOの仕事が感謝されにくい分、**辞めると言った瞬間にだけ初めて必要とされる**という逆転が起きるからです。長く報われなかった人ほど、この一言で揺らぎます。

ただ、冷静に見てください。その評価は、あなたが辞意を示す前には口に出されていなかったはずです。

### パターン2：条件を出してくる

昇給、昇格、アサイン変更。これは一見すると前進に見えます。

{{< note type="info" title="条件提示を受けるときの判断軸" >}}
判断すべきは金額ではなく「その条件が、辞めると言わなければ出なかったか」です。出なかったのなら、同じ構造はこれからも続きます。次に待遇を動かしたいとき、また辞表をちらつかせる必要が出てきます。それは健全な関係ではありません。
{{< /note >}}

実際、条件を飲んで残った人の多くが1〜2年以内に再び転職活動を始めます。不満の原因が待遇だけではなかったケースが大半だからです。

→ 自分の不満がどこにあるのかは[PMOを辞めたいと思ったときに確認すること](/posts/pmo-quit-checklist/)で整理できます。

### パターン3：時期を引き延ばす

「この案件の区切りまで」「後任が決まってから」。もっとも実害が大きいパターンです。

案件に区切りはいくらでも作れますし、後任採用は会社の責任であってあなたの責任ではありません。**引き延ばしは、断らない限り無限に続きます。**

---

## 辞められる人が準備していること

引き止めを突破できるかどうかは、交渉力ではなく準備で決まります。

### 1. 退職日を先に決めてから切り出す

「辞めたいと思っている」ではなく「○月○日で退職します」と伝える。相談の形にすると、会社は交渉の余地があると判断します。

民法上、期間の定めのない雇用は申し入れから2週間で終了できます。実務では就業規則の1〜2ヶ月前申告に合わせるのが穏当ですが、**最終的な決定権が自分にあることは知っておく**と、引き延ばしに流されません。

### 2. 引き継ぎ資料を先に作っておく

これが最も効きます。辞意を伝える前に、課題管理の経緯・関係者マップ・定例の運営手順を文書化しておく。

「後任が決まらないから」という理由を、資料の存在で無力化できます。しかもこの作業は、**自分の仕事を言語化する訓練**にもなり、職務経歴書の材料にもなります。

→ 言語化の型は[PMOの職務経歴書の書き方](/posts/pmo-resume-writing/)が使えます。

### 3. 退職理由を「不満」で語らない

「評価されない」「調整ばかり」と伝えると、会社は改善を提案できてしまい、交渉が始まります。

{{< voice speaker="reader" >}}
正直に理由を言わないのは、不誠実な気がしてしまいます。
{{< /voice >}}

{{< voice speaker="owner" >}}
嘘をつく必要はありません。「やりたい方向が決まった」という前向きな理由に寄せるだけです。不満を並べると論点が改善提案にすり替わり、辞める話が先に進まなくなる。これは誠実さの問題ではなく、話を終わらせるための技術です。
{{< /voice >}}

## 引き止めに応じてよい唯一のケース

ひとつだけ、残る判断が合理的な場合があります。

**提示された条件が、転職先で得ようとしていたものを本当に満たしているとき**です。役割が変わり、権限が増え、それが口約束でなく異動や辞令として形になるなら、残る価値はあります。

逆に言えば、口頭の約束だけなら応じるべきではありません。形にならない約束は、半年後には誰も覚えていません。

→ 残る選択を真剣に検討するなら[SIer PMOが社内に残る選択](/posts/sier-pmo-stay-inside/)も読んでみてください。

## 切り出しから退職日までの進め方

引き止めに備えるなら、順番が重要です。多くの人は「辞意を伝える」から始めてしまい、そこから準備を始めるので主導権を失います。

{{< comparison-table title="退職を切り出す前後の進め方" >}}
| 時期 | やること | 目的 |
|------|----------|------|
| 内定前 | 引き継ぎ資料の下書きを作る | 「後任がいない」を潰す |
| 内定後すぐ | 入社日を仮決めし、逆算で退職日を決める | 交渉の軸を自分で持つ |
| 切り出し当日 | 直属上長に、日付を明示して伝える | 相談ではなく報告にする |
| 以降 | 条件提示は「ありがたいが決めている」で一貫 | 論点を増やさない |
{{< /comparison-table >}}

特に大事なのは2段目です。入社日から逆算して退職日を固定しておくと、「いつなら大丈夫か」という問いに巻き込まれません。

{{< note type="info" title="伝える相手を間違えない" >}}
最初に伝えるのは直属の上長です。先に人事やさらに上の役職者に話すと、上長の面子を潰して話がこじれます。順序を守るだけで、無用な摩擦はかなり減ります。
{{< /note >}}

---
## まとめ

- 引き止めは「あなたが優秀だから」ではなく「会社が困るから」起きる
- 典型は情に訴える・条件を出す・時期を引き延ばすの3パターン
- 辞められる人は、退職日を決め、引き継ぎ資料を先に作り、理由を不満で語らない
- 条件提示に応じてよいのは、それが辞令など形になる場合だけ

そもそも転職先が決まっていなければ、この関門に立つことすらできません。まずは市場を見るところからです。
